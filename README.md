# Tiempo de lectura

Plugin de WordPress que muestra al principio de cada entrada, cuánto se tarda en leerla.

Lo he hecho como práctica dentro del programa WordPress Credits (Developer Track).

## Cómo funciona

Cuenta las palabras de la entrada y calcula los minutos a 200 palabras por minuto.
El resultado se añade antes del contenido con el filtro the_content.

## Instalación

1. Descarga el repositorio y copia la carpeta en wp-content/plugins.
2. Activa el plugin en el escritorio de WordPress.
3. Abre cualquier entrada: verás el tiempo de lectura encima del texto.
